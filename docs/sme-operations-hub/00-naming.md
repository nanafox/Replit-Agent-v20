# Naming Direction

Status: **Leading candidate, not final**

## Proposed working name

# Nuvio

## Preferred tagline

> A clearer way to run business.

## Why it fits

- Short and easy to say.
- Works across markets and does not limit the product to one industry.
- Feels modern without being overly technical.
- Can stretch from inventory and sales into wider business operations.
- Has a friendly, polished SaaS character.

## Recommended descriptor

The name should appear with a clarifying descriptor until the product has stronger recognition:

> **Nuvio — Business operations for growing SMEs**

Other descriptor options:

- **Nuvio — Run every branch with confidence**
- **Nuvio — One workspace for every branch**
- **Nuvio — A simpler way to run your business**

The preferred combination for now is:

> **Nuvio**  
> **A clearer way to run business.**

## Naming risk

A quick category scan found existing software, finance, consulting, and payment-related businesses using the Nuvio name or close variants. This does not automatically disqualify the name, but it means Nuvio should not be treated as cleared or ownable yet.

## Before final approval

- Check `nuvio.com`, `nuvio.app`, and relevant alternative domains.
- Check social handles for Nuvio and likely prefixed variants.
- Search software and business-service trademarks in intended markets.
- Check whether an existing Nuvio product occupies the same operational software category.
- Decide whether the product should use a modifier such as `Nuvio Ops` or `Get Nuvio` if the base name is too crowded.

## Current decision

Use **Nuvio** in planning documents and early product language as the proposed working name. Do not create final brand assets, register domains, or treat the name as legally cleared until the availability review is complete.
